# Детектор лжи — AI

Одностраничное веб-приложение в одном файле: **`lie-detector.html`**.
Определяет **маркеры обмана** по тексту или по голосу. Работает полностью локально
(никаких серверов, зависимостей и внешних библиотек) — просто откройте файл в браузере.

## Возможности

- **📝 Анализ текста** (русский и английский автоопределяются):
  - доля отрицаний, оговорки («кажется», «возможно»),
  - чрезмерные заверения («честно», «клянусь»),
  - дистанцирование (мало «я»),
  - конкретика (цифры, даты, имена, время) — её у лжецов меньше,
  - эмоциональная бедность,
  - дословные повторы чужих фраз (эхо).
- **🎙️ Анализ голоса**: запись в микрофон или загрузка аудиофайла (mp3/wav/ogg/m4a/webm).
  Извлекаются: высота тона (F0), вариативность тона, микрофлуктуации, доля пауз, энергия.
  Показывается осциллограмма + контур тона.
- **Индекс обмана 0–100** с объяснением каждого сигнала и уровнем достоверности.

## Честные ограничения (важно!)

Научные мета-анализы (Bond & DePaulo, 2006; 206 исследований, 24 483 наблюдателя)
показывают: точность людей ~54%, специалистов — не лучше. Ни одна система в мире
не распознаёт ложь по тексту или голосу надёжнее «монетки» на реальных данных;
на лабораторных датасетах системы ИИ показывают 60–80%, но это не переносится на жизнь.

Поэтому приложение — **учебно-аналитический инструмент**:
оно подсвечивает статистические маркеры из опубликованных исследований
(Pennebaker/LIWC, DePaulo 2003, Vrij) и помогает сфокусироваться на проверке фактов.
**Результат нельзя использовать как улику или «суд» над человеком.**

## Использование

1. Откройте `lie-detector.html` в браузере (Chrome/Edge/Firefox).
2. Вкладка **Текст**: вставьте высказывание → «Проанализировать» (или Ctrl+Enter).
3. Вкладка **Голос**: нажмите «Записать речь» (нужно разрешение на микрофон)
   или «Загрузить аудио». Лучше — прямой ответ на вопрос/обвинение длительностью 15–60 с.
4. Раздел «Как это работает» внутри приложения — методология и источники.

> В sandboxed-превью (iframe без `allow-microphone`) запись в микрофон может быть
> заблокирована браузером — в этом случае используйте загрузку аудиофайла.

## Публикация на GitHub

```bash
# 1) Создайте пустой репозиторий на github.com (например, lie-detector-ai)
# 2) Добавьте его как origin и отправьте:
git remote add origin https://github.com/<ваш-логин>/lie-detector-ai.git
git push -u origin main
```

**Бонус — живой демо-сайт:** в настройках репозитория включите
*Settings → Pages → Source: Deploy from a branch → main / (root)*.
Файл `index.html` — копия приложения, поэтому демо сразу заработает
по адресу `https://<ваш-логин>.github.io/lie-detector-ai/`.

> Важно: в браузере запись с микрофона требует HTTPS (GitHub Pages даёт его автоматически).
