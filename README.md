# Детектор лжи — AI

> 🔗 **Живая версия (демо онлайн):** [https://belknikolja-arch.github.io/lie-detector-ai/](https://belknikolja-arch.github.io/lie-detector-ai/) — просто откройте, работает в браузере.

Одностраничное веб-приложение в одном файле: **`lie-detector.html`**.
Определяет **маркеры обмана** по тексту или по голосу. Работает полностью локально
(никаких серверов, зависимостей и внешних библиотек) — просто откройте файл в браузере.

## Что нового в v1.5 (двуязычное интервью)

- **Интервью на двух языках**: вопросы, уточняющие вопросы, сводка и экспорт отчёта — на русском или английском.
- **Переключатель «Авто / RU / EN»**: «Авто» определяет язык по теме («the missing documents» → EN-вопросы), RU/EN — принудительное переключение.
- Локализованы: живая строка прогресса («answers checked: N • current average index: X/100»), заголовки сводки и verdict, экспорт («Deception Detector AI — Interview», Topic/Answer/Index, англоязычный дисклеймер).
- Ядра: новые чистые функции `interviewLang(topic, pref)`, `verdictOfEn(score)`; `generateQuestions` и `genFollowUps` принимают язык (RU-поведение — без изменений, покрыто регрессиями).

## Что нового в v1.4 (усиление существующих модулей)

- **Текст**: два новых маркера — «размытые указания» (где-то/кто-то/на днях) и «повышенная интенсивность» (восклицания, выделенные слова); подсветка предложений в результате (заверения / отрицания / оговорки / конкретика); уровень достоверности теперь учитывает и число найденных маркеров.
- **Голос**: новые метрики — ритм речи (запуски/остановки в секунду) и тренд интонации; график: осциллограмма + линия тона + затемнение пауз; сигнал «рваный ритм».
- **Эталон**: сравнение расширено до 7 метрик (добавлены ритм и тренд, веса пересчитаны); старые эталоны без новых метрик поддерживаются; авто-пометки о возрасте эталона (>7 дней) и коротком эталоне (<10 с).
- **Две версии**: новый сильнейший сигнал «отрицание vs утверждение» (слово отрицается в одной версии и утверждается в другой, штраф до 25) и «перекрываемость лексики» (общий коэффициент; <20% — пометка «разные по существу»).
- **Интервью**: живой средний индекс по ходу допроса, лимит 2 уточнений на вопрос, видимое предупреждение о коротких ответах.
- **История/экспорт**: история хранит все типы (📝 текст — кликабельный, 🎙 голос и ⚖️ сравнение — просмотрные); экспорт с фидбеком «✓ Сохранено и скопировано»; плавная анимация датчика.

## Возможности

- **📝 Анализ текста** (русский и английский автоопределяются):
  - доля отрицаний, оговорки («кажется», «возможно»),
  - чрезмерные заверения («честно», «клянусь»),
  - дистанцирование (мало «я»),
  - конкретика (цифры, даты, имена, время) — её у лжецов меньше,
  - эмоциональная бедность,
  - дословные повторы чужих фраз (эхо).
- **🎙️ Анализ голоса**: запись в микрофон или загрузка аудиофайла (mp3/wav/ogg/m4a/webm).
  Извлекаются: высота тона (F0), вариативность тона, микрофлуктуации, доля пауз, энергия.
  Показывается осциллограмма + контур тона.
- **🗣 Интервью** (v1.3): задаёте тему расследования — приложение выдаёт список
  открытых вопросов (полное рассказывание, время, место, последовательность, свидетели,
  память, чувства). Каждый ответ анализируется маркерами обмана, а система генерирует
  уточняющие вопросы по найденным «слабым местам» (отрицания → «что именно вы делали?»,
  оговорки → «давайте точность», мало деталей → «какие цифры, имена, время?»).
  Итоговая сводка по всем ответам сохраняется в отчёт.
- **⚖️ Сравнение двух версий** (v1.2): вставляете два рассказа об одном событии —
  система находит расхождения в проверяемых деталях (цифры, время, даты, день/время суток,
  имена с учётом формы слова) и общие точки, вычисляет **индекс согласованности 0–100**.
  Техника «стабильности версии» (Vrij, PEACE) — один из немногих реально работающих
  приёмов проверки фактов.
- **🕘 История + экспорт** (v1.2): последние текстовые анализы хранятся локально
  (клик — повторный анализ), любой результат (текст/голос/сравнение) можно сохранить
  в `.txt`-отчёт.
- **📐 Сравнение с эталоном голоса** (v1.1): задаёте «базовую линию» — спокойную запись
  того же человека (30–60 с, запись или файл). При каждом анализе показывается, как голос
  отклоняется от привычного: средний тон, микрофлуктуации, паузы, энергия +
  **индекс отклонения 0–100**. Эталон хранится локально (localStorage) и удаляется одной кнопкой.
- **Индекс обмана 0–100** с объяснением каждого сигнала и уровнем достоверности.

## Честные ограничения (важно!)

Научные мета-анализы (Bond & DePaulo, 2006; 206 исследований, 24 483 наблюдателя)
показывают: точность людей ~54%, специалистов — не лучше. Ни одна система в мире
не распознаёт ложь по тексту или голосу надёжнее «монетки» на реальных данных;
на лабораторных датасетах системы ИИ показывают 60–80%, но это не переносится на жизнь.

Поэтому приложение — **учебно-аналитический инструмент**:
оно подсвечивает статистические маркеры из опубликованных исследований
(Pennebaker/LIWC, DePaulo 2003, Vrij) и помогает сфокусироваться на проверке фактов.
**Результат нельзя использовать как улику или «суд» над человеком.**

## Использование

1. Откройте `lie-detector.html` в браузере (Chrome/Edge/Firefox).
2. Вкладка **Текст**: вставьте высказывание → «Проанализировать» (или Ctrl+Enter).
3. Вкладка **Голос**: нажмите «Записать речь» (нужно разрешение на микрофон)
   или «Загрузить аудио». Лучше — прямой ответ на вопрос/обвинение длительностью 15–60 с.
   По желанию задайте **эталон** (спокойная речь 30–60 с) — тогда в результате появится
   блок «Сравнение с эталоном».
4. Вкладка **Две версии**: две версии одного события → «Сравнить версии» — расхождения и общий индекс.
5. Вкладка **Интервью**: тема → «Начать интервью» → ответьте на вопросы → «Сводка по интервью» → экспорт.
5. Раздел «Как это работает» внутри приложения — методология и источники.

> В sandboxed-превью (iframe без `allow-microphone`) запись в микрофон может быть
> заблокирована браузером — в этом случае используйте загрузку аудиофайла.

## Публикация на GitHub

```bash
# 1) Создайте пустой репозиторий на github.com (например, lie-detector-ai)
# 2) Добавьте его как origin и отправьте:
git remote add origin https://github.com/<ваш-логин>/lie-detector-ai.git
git push -u origin main
```

**Бонус — живой демо-сайт:** в настройках репозитория включите
*Settings → Pages → Source: Deploy from a branch → main / (root)*.
Файл `index.html` — копия приложения, поэтому демо сразу заработает
по адресу `https://<ваш-логин>.github.io/lie-detector-ai/`.

> Важно: в браузере запись с микрофона требует HTTPS (GitHub Pages даёт его автоматически).
